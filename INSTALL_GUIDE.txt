WIFITE ANDROID v2.0 - INSTALLATION GUIDE
=========================================

REQUIREMENTS:
- Android Studio Arctic Fox or newer
- Android SDK 26+
- Target SDK 34
- 2GB RAM minimum
- Kotlin 1.8+

STEPS:
1. Extract Wifite-Android-v2.0-AltayHR.zip
2. Open with Android Studio
3. File > Open > select app directory
4. Gradle sync automatic
5. Click Run or Build > Build APK
6. Install on device with minimum Android 8.0

PERMISSIONS:
- Wi-Fi Access (Required)
- Location (Required - Android 10+)
- Storage (Optional)

TESTING:
- Grant all permissions
- Tap START SECURITY AUDIT
- Select Wi-Fi network
- Choose wordlist
- Start password cracking
